## 📌 Overview
Vital-Mart is a **modern healthcare e-commerce platform** designed to provide seamless online shopping for medical products.

It includes:
- 🛒 Smart cart system  
- 💳 Smooth checkout flow  
- 📦 Order tracking  
- 🤖 AI chatbot assistance  

---

## ⚡ Features

✨ **User Experience**
- Responsive & modern UI
- Fast navigation
- Mobile-friendly design

🛍️ **E-Commerce Core**
- Add to cart / remove items
- Dynamic price calculation
- Checkout system

🤖 **AI Integration**
- Chatbot for user assistance

📦 **Order System**
- Order tracking simulation
- Status updates
